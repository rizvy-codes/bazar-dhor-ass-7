# বাজার দর (Bazar Dor)

প্রয়োজনীয় পণ্যের আজকের দাম এক নজরে। চাল, ডাল, তেল, সবজি, মাছ, মাংস, ডিম ও মসলার দাম, পরিবর্তন এবং বাজারভিত্তিক তথ্য দেখা যায়।

## Technologies

- Next.js (App Router)
- TypeScript
- Tailwind CSS + DaisyUI
- Better Auth (Email, Google, GitHub)
- MongoDB
- react-toastify

## Features

1. হোমপেজে আজ দাম বেড়েছে, আজ দাম কমেছে এবং সব পণ্যের কার্ড।
2. ক্যাটাগরি পেজে দাম অনুযায়ী সাজানো (কম থেকে বেশি / বেশি থেকে কম)।
3. প্রোডাক্ট ডিটেইল পেজে সর্বনিম্ন, গড়, সর্বোচ্চ দাম এবং বাজারভিত্তিক টেবিল।
4. ইমেইল, Google ও GitHub দিয়ে সাইন ইন / সাইন আপ।
5. প্রোফাইলে নাম আপডেট এবং লগ আউট।
6. প্রাইস টিকার (marquee), 404 পেজ এবং লোডিং স্টেট।
7. মোবাইল, ট্যাবলেট ও ডেস্কটপে রেসপন্সিভ লেআউট।
